 ## Results Overview

 This folder contains outputs generated by `CS555_advanced_boston.R` and the knitted report.

 - `model_comparison_results.csv`: RMSE and R² on the test set across models
 - `sessionInfo.txt`: Reproducibility details (R version, packages)
 - `../figures/` contains saved figures used in the report
 - `report.html` (generated from `report.Rmd`) provides a readable summary

 ### Highlights
 - Best performance from GBM/Random Forest (RMSE ≈ 3.1–3.2)
 - Linear regression shows heteroskedasticity and non-normal residuals
 - Strong relationships: `rm` (+), `lstat` (-), `ptratio` (-)
